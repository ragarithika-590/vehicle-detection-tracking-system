Vehicle Detection and Tracking System

Comprehensive Technical Overview & System Specification

1. Abstract & Objective

Automated traffic monitoring and vehicle counting are fundamental pillars of modern Intelligent Transportation Systems (ITS) and smart city infrastructure. Traditional manual traffic counting or sensor-loop systems are labor-intensive, costly, and prone to environmental degradation.

This project presents an end-to-end web-based computer vision solution built with Django, Ultralytics YOLOv8, ByteTrack, and OpenCV. The system processes uploaded traffic video streams, detects multi-class vehicles (Car, Bus, Truck, Motorcycle), tracks object trajectories across sequential frames to assign persistent IDs, and enforces strict duplicate-prevention logic to compute accurate traffic metrics saved in an SQLite database.

2. System Architecture & Processing Pipeline

User Browser ---> Django Web App ---> Video Upload Form
|
v
SQLite DB <--- Results Dashboard <--- OpenCV VideoReader
|
v
Annotated Output Video <--- Unique Count Filter <--- YOLOv8 + ByteTrack Tracking
  • YOLOv8 Detection: Uses a single-stage neural network to predict bounding boxes and class probabilities for car, bus, truck, and motorcycle.
  • ByteTrack Multi-Object Tracking: Retains high-confidence and low-confidence detection boxes to solve trajectory breakage and visual occlusions.
  • Duplicate Prevention Mechanism: Maintains a session hash map of (vehicle_class, track_id). Each vehicle is counted exactly once when first tracked.
  • OpenCV Video Writer: Draws colored bounding boxes, track ID labels, and real-time top-banner HUD counts directly onto output video frames.

Key Use Cases:

  • Highway Traffic Volume Analysis: Automatic vehicle count monitoring during rush hours.
  • Urban Infrastructure Planning: Evaluating road capacity requirements based on truck vs. car ratios.
  • Toll Booth Automation: Classifying incoming vehicle types for dynamic fee calculation.
  • Smart City Surveillance: Real-time anomaly and traffic density monitoring via webcam/CCTV feeds.
